## Development Rule

Work one step at a time. Complete the current phase fully — frontend, backend, database, admin, integration, and verification as applicable — before moving to the next phase.

Do not rewrite working functionality unnecessarily. Do not add unrelated features. Keep implementation conversations point-to-point.
